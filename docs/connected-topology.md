# Connected topology acceptance correction

Replaces the reaction cards inside the whiteboard with compound nodes and reaction junctions. Participant edges terminate on node/junction boundaries with role-directed arrowheads, coefficient labels and the existing evidence-filtered style. A→B, B→C and B→D visibly share B. Multiple reactants and coproducts connect to one junction. An explicitly recorded reverse reaction C→B follows a separate backward path and preserves its own evidence; no reversible/equilibrium claim is inferred from one forward observation.

The small deterministic directed layout uses no new graph dependency. Nodes have one position per explicit compound ID in each atmosphere lane; names never merge identities. Same-ID conflicting structural attributes are isolated and flagged. Nodes offer all connected reactions in the source selector. Filtering, scope guards, matched refutations, unknown handling and evidence review rules remain in the existing aggregation engine. Hidden/unknown records do not acquire edges. Fit view displays the complete topology; mobile search/zoom enables readable detail and pan moves within the canvas.

A persistence limitation discovered during this correction required a narrow additive candidate: case-owned compounds cannot reuse stable IDs across different cases. `20261002110000_compound_identity_links.sql` records an explicitly human-reviewed equivalence between compounds in two stable reaction definitions. The UI requires deliberate selections, reason and attestation. The RPC checks structural context, node type, formula, charge, stereo/protonation, derives actor/time, enforces owner RLS and expected revision, and appends history. There is no name-based or AI merge. Unknown attributes remain unknown and require human judgment. Withdrawing a link restores distinct topology unless another explicit active equivalence path remains. Raw case payloads and evidence are never rewritten.

The renderer also supports literal SAME-ID B fixtures, and a separate domain test joins different case IDs through an explicit reviewed link. SQL tests exercise storage, retries, revision conflict, structural mismatch, withdrawal history, direct-write rejection and cross-owner isolation. Candidate migration remains unapplied to hosted Supabase.
